# Результаты нагрузочного теста

Измерения получены 23 октября 2026 года на локальном Minikube после успешного
развертывания `Qwen/Qwen2.5-0.5B-Instruct` в vLLM 0.27.0 CPU.

Окружение: Windows/WSL2, Docker Desktop, Minikube 1.39.0, Kubernetes 1.37.0,
Intel Core 5 210H (8 физических ядер, 12 логических процессоров), 31.6 ГиБ RAM.
Minikube выделено 6 vCPU и 10 ГиБ RAM. Параметры модели: BF16,
`MAX_MODEL_LEN=2048`, `MAX_NUM_SEQS=8`, `MAX_NUM_BATCHED_TOKENS=2048`.

Параметры: 4 запроса, concurrency 2, максимум 16 выходных токенов.

|---|---:|---:|---:|---:|---:|---:|---:|

| long | 4/4 | 4.031 | 5.376 | 7.332 | 7.542 | 4.35 | 0.27 |

Во втором запуске одинаковые длинные префиксы повторялись, и vLLM сообщил
`Prefix cache hit rate: 69.4%`. Поэтому уменьшение TTFT длинного prompt — ожидаемый
эффект prefix caching, а не ускорение самого холодного prefill. Эти два запуска
показывают разные режимы и не должны сравниваться как идентичные эксперименты.

Сгенерированные скриптом JSON и Markdown-файлы игнорируются Git, чтобы повторные
локальные запуски не засоряли историю. Эта страница содержит проверенные итоговые
цифры, предназначенные для репозитория.
